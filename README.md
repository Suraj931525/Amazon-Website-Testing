# Amazon Website Testing – Manual Testing Project

## Project Overview

This project focuses on testing the functionality, usability, navigation, and overall user experience of the Amazon India website.

The objective was to perform manual testing from a real user's perspective, identify functional issues, explore confusing user flows, and document bugs and usability improvements.

**Application:** [Amazon India](https://www.amazon.in/)

**Testing Type:** Manual Testing, Functional Testing, Exploratory Testing, UAT, Cross-Browser Testing

**Testing Environment:** Windows 11

**Browsers:** Google Chrome and Microsoft Edge

## Objectives

- Verify important Amazon website functionalities.
- Prepare and execute manual test cases.
- Identify and document application bugs.
- Perform exploratory testing using different test inputs.
- Evaluate user experience and confusing navigation flows.
- Verify basic functionality across different browsers.
- Suggest automation testing opportunities.

## Testing Activities

### 1. Manual Testing
- Website launch verification
- Product search functionality
- Product details verification
- Brand filtering and price sorting
- Add to Cart functionality
- Cart quantity update
- Remove from Cart
- Checkout navigation

### 2. Bug Reporting

Identified and documented issues with:
- Bug ID and Summary
- Bug Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity and Priority
- Supporting screenshots/evidence where available

### 3. Exploratory Testing

Performed exploratory testing using different scenarios, including:
- Invalid search inputs
- Special characters in search
- Numbers and mixed-character inputs
- Multiple Add to Cart clicks
- Frequent filter switching
- Unavailable product variants
- Repeated cart quantity updates
- Empty search functionality

### 4. User Acceptance Testing (UAT)

Evaluated the website from a real user's perspective and identified confusing user journeys related to:
- Account, profile and settings options
- Customer support navigation
- Order tracking and courier details

### 5. Cross-Browser Testing

Prepared and executed test cases in:
- Google Chrome
- Microsoft Edge

Verified website launch, product search, product details, Add to Cart and cart quantity update.

### 6. UI/UX Testing

Identified usability improvement opportunities related to:
- Filter sidebar scrolling
- Sponsored product relevance
- Account navigation
- Customer support accessibility
- Shopping list navigation
- Profile management
- Overall website navigation

## Automation Testing Suggestions

A proposed automation flow was documented using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

Suggested automation coverage:
1. Launch Amazon website.
2. Search for a product.
3. Select a product.
4. Verify product details.
5. Add product to cart.
6. Verify cart details.
7. Navigate to checkout.

**Note:** The automation document describes the proposed automation approach and flow. This repository primarily contains manual testing documentation.

## Test Summary

The testing activities covered important shopping functionalities, exploratory scenarios, cross-browser checks and usability observations.

Several functional and usability issues were documented for further investigation.

Some additional features were not tested due to limited testing time, as mentioned in the Test Summary Report.
